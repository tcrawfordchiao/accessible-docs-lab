# Getting started

## Prerequisites

Before you begin, make sure you:

- Have an administrator account.
- Have permission to create a workspace.
- Know the name of the operational procedure you want to publish.

## Create and publish your first procedure

1. Sign in to the platform.
2. Open **Workspaces**.
3. Select **Create workspace**.
4. Enter a workspace name and select **Create**.
5. Open the new workspace and select **New procedure**.
6. Enter a title and add the procedure content.
7. Select **Publish**.

## Expected result

The procedure appears in the workspace with a **Published** status.

## If publication fails

If the procedure does not publish, check that all required fields are complete.

If a required field is missing:

1. Return to the procedure.
2. Complete the missing field.
3. Select **Publish** again.
